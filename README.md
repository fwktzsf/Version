# Viral Stock Poster Updates

这是 **爆款股票海报生成器** 的公开更新仓库。

这里只存放发布版本和更新清单，不包含私有源码、30 万数据池或内部配置。

软件读取根目录的 `latest.json` 检查新版本，并在用户确认后下载安装程序。

## 更新流程

1. 私有源码仓库完成测试并构建 Windows 安装程序。
2. 将新的安装程序发布到本仓库 `releases/vX.Y.Z/`。
3. 更新 `latest.json` 的版本号、SHA-256、大小和下载地址。
4. 已安装的软件启动后自动检测更新，也可以手动点击“检查更新”。

## 安全说明

软件会在启动安装程序前校验 SHA-256。代码签名证书配置完成后，还会继续使用 Windows Authenticode 签名。
